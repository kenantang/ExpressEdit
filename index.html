ExpressEdit

Fast Editing of Stylized Facial Expressions with Diffusion Models in Photoshop

Kenan Tang, Jiasheng Guo, Jeffrey Lin, Yao Qin
University of California, Santa Barbara

Paper Code Dataset RAG Demo

Introduction

ExpressEdit is a free, fully open-source Photoshop plugin for editing stylized facial expressions on illustrated characters. It is powered by the SPICE image editing workflow and a curated database of 135 Danbooru expression tags.

Unlike proprietary image editing models (GPT, Grok, Nano Banana 2, FLUX.2), ExpressEdit produces clean results without global noise or watermarks, supports precise numerical control via native Photoshop operations, and completes each edit in under 3 seconds on a single consumer-grade GPU.

ExpressEdit generates diverse stylized expressions on original images, supporting both multi-word descriptions and emoticons as input.

Expression Database

ExpressEdit includes a database of 135 curated expression tags from Danbooru. Each tag contains a definition, alternative tags in Japanese, Chinese, and Korean, 5 example images across different characters, and 5 example stories in each of four languages.

Tags can be combined (e.g. smile, blush) for richer expressions, and eyes and mouth can be edited separately for more combinations. You can use the RAG demo to retrieve the right tag from a free-form story description.

No Global Noise

Baseline models introduce visible noise across the entire image with every edit. Over multiple steps, this noise accumulates and corrupts the image. ExpressEdit edits only the selected region, with no modifications outside that area. Even after 100 repeated edits on the same region, the only artifacts appear around the selection edge and can be repaired in one step.

Baseline models introduce destructive noise after each editing step. ExpressEdit produces clean, non-destructive results even over many iterations.

Precise Editing

All baseline models fail to follow precise numeric instructions like "reduce iris diameter by 50%." With ExpressEdit, you use Photoshop's native Select and Scale to resize the element, then generate. The diffusion model fills in the gap cleanly, without specifying numbers in the prompt.

ExpressEdit precisely reduces iris size by 50% using a simple Photoshop transformation. All baseline models fail on this task.

Quick Start

The editing workflow has four steps:

  1. Set the prompt. Type an expression tag (e.g. smile, clenched teeth, +_+) into the plugin prompt box.
  2. Apply a transformation (optional). Use Scale, Liquify, or the Brush to roughly hint at the desired expression. This step can be skipped for 100 out of 135 tags.
  3. Select the region. Use Quick Selection or the Selection Brush to cover the area to be edited. The selection does not need to be precise.
  4. Click Generate. ExpressEdit returns a clean result as a new layer.

The ExpressEdit workflow: start with an original image, apply an optional transformation, select the region, and generate.
