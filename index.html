ExpressEdit: Fast Editing of Stylized Facial Expressions with Diffusion Models in Photoshop

Kenan Tang, Jiasheng Guo, Jeffrey Lin, Yao Qin
University of California, Santa Barbara

📄 Paper 💻 Code 🤗 Dataset 🎭 RAG Demo

Introduction

ExpressEdit is a free, fully open-source Photoshop plugin for editing stylized facial expressions on illustrated characters. It is powered by the SPICE image editing workflow and a curated database of 135 Danbooru expression tags.

Unlike proprietary image editing models (GPT, Grok, Nano Banana 2, FLUX.2), ExpressEdit produces clean results without global noise or watermarks, supports precise numerical control via native Photoshop operations, and completes each edit in under 3 seconds on a single consumer-grade GPU.

ExpressEdit generates diverse stylized expressions, including multi-word descriptions ("clenched teeth") and emoticons ("@_@").

Why ExpressEdit?

No Global Noise

Baseline models introduce visible noise across the entire image with every edit. Over multiple editing steps, this noise accumulates and corrupts the image. ExpressEdit edits only the selected region, leaving the rest of the image completely untouched. Even after 100 repeated edits on the same region, the only artifacts appear around the selection edge and can be repaired in one step.

After 8 iterative edits, noise from Nano Banana 2 Pro corrupts the image. ExpressEdit maintains clean results.

Pixel-Precise Editing

All baseline models fail to follow precise numeric instructions like "reduce iris diameter by 50%." With ExpressEdit, you simply use Photoshop's Select and Scale to resize the iris, then generate — the diffusion model fills in the gap. No numeric prompt required.

ExpressEdit precisely reduces iris size by 50% using a simple transformation. All baseline models fail on this task.

Works with Liquify

Photoshop's Liquify tool is the most intuitive way to drag facial elements around, but it leaves heavy deformation artifacts. ExpressEdit automatically repairs these distortions into natural results, so you can use Liquify casually without worrying about precision.

Extreme distortions from casual Liquify usage are repaired into natural expressions by ExpressEdit.

Quick Start

The editing workflow has 4 steps:

  1. Set the prompt. Type an expression tag (e.g. smile, clenched teeth, +_+) into the plugin prompt box. You can use the RAG demo to find the right tag from a story description.
  2. (Optional) Apply a transformation. Use Liquify, Scale, or the Brush to roughly hint at the desired expression. This step can be skipped for 100 out of 135 tags.
  3. Select the region. Use Quick Selection or the Selection Brush to cover the area to be edited. The selection does not need to be precise.
  4. Click Generate. ExpressEdit returns a clean result as a new layer. Merge it with the original when satisfied.

The ExpressEdit workflow: Original → Transform (optional) → Select → Generate result.

Expression Database

ExpressEdit includes a database of 135 curated expression tags from Danbooru, each with:

  • A definition from the official Danbooru wiki
  • Alternative tags in Japanese, Chinese, and Korean (from Pixiv)
  • 5 example images generated across different characters
  • 5 example stories in each of English, Chinese, Japanese, and Korean

Tags can be combined (e.g. smile, blush) for richer expressions. Eyes and mouth can also be edited separately for even more combinations.

Usage Tips

⚠️ Model version consistency. The base model used for generating the original image and for editing should ideally be the same version. Switching between model versions (e.g., WAI-illustrious v16 vs v17) can cause subtle style mismatches such as different default lighting or facial proportions.
💡 Denoising strength. The default 70% works well in most cases. For edits involving hair or other fine details, reducing to ~50% can avoid artifacts on weaker edges that may not be captured by the Canny edge ControlNet.
💡 Selection size. Larger selections generally produce better results. When the selection is too small, the model operates on limited context and is more likely to produce edge mismatches.
💡 Context dots. When editing only a sub-region of the face (just the eyes or mouth), adding context dots around the mask helps the model understand the full facial layout.
💡 Speed-up LoRA. The Lightning LoRA cuts inference from ~4s to ~2s. Use it for rapid prototyping; use full 30 steps for final renders.
💡 Transformation-free tags. 100 out of 135 tags can be edited without any Photoshop transformation. The remaining 35 (flagged in the plugin documentation) require a quick Liquify or Scale step.

Installation

Please refer to the GitHub repository for installation instructions. ExpressEdit requires:

  • Adobe Photoshop (version 27.4.0 or later)
  • A single consumer-grade GPU with 24 GB VRAM (e.g., NVIDIA RTX 4090)
  • The SPICE backend
  • WAI-illustrious-SDXL as the base model
  • A midsize Canny edge ControlNet model for SDXL

Applications

ExpressEdit is designed for:

  • Character design and iteration — quickly explore different expressions on a character
  • Storyboard visualization — match character expressions to narrative beats
  • Comic and manga production — edit expressions across panels efficiently
  • Illustration workflows — fix AI-generated expression artifacts while maintaining style consistency
